# VALORANT AIコーチ

自分の試合動画（1試合分・30分〜1時間程度）をアップロードすると、
プロ・上位ランクの学習動画と比較して「何が良くて何がダメだったか」を
**ラウンドごとに**フィードバックするWebアプリです。

## 仕組み

```
[学習フェーズ]
プロ / ダイヤ帯以上の動画 ──▶ 動画解析 ──▶ ランク帯別ベンチマーク (SQLite)
                                              │
[コーチングフェーズ]                            ▼
自分の動画 + 現在のランク ──▶ 動画解析 ──▶ 次のランク帯の基準と比較
                                              │
                                              ▼
                              ルールベース分析 + Claude によるAIコーチング
                              （総評 / 良かった点 / 改善点 / ラウンド別分析）
```

### 動画解析でやっていること

- **ラウンド検出**: 画面全体のシーンチェンジ（バイフェーズ遷移・リザルト画面）を
  ヒストグラム差分で検出し、VALORANTのラウンド長制約（45〜200秒）で区切ります
- **交戦検出**: 画面右上のキルフィード領域の赤/緑ハイライトから交戦イベントを推定します
- **指標化**: ラウンドごとに「初動交戦までの秒数」「交戦回数」「ラウンド時間」などを算出します
- **代表フレーム抽出**: 各ラウンドの交戦シーンをAIコーチング用に切り出します

### コーチング

1. **ルールベース分析**（APIキー不要）: 利用者の指標を「次のランク帯」のベンチマークと
   比較し、ラウンドごとの所見と重点ポイントを提示します
2. **AIコーチング**（`ANTHROPIC_API_KEY` 設定時）: Claude が指標と実際のプレー画面
   （代表フレーム）を見て、クロスヘアの高さ・ポジション・エコノミー判断などを含む
   詳細なコーチングレポートを生成します
3. **動画を見ながら解説を確認**: 結果画面にアップロードした動画のプレイヤーが埋め込まれ、
   各ラウンドの「▶ この場面を見る」「▶ 初動交戦を見る」で該当シーンにジャンプできます

## セットアップ

### かんたん起動（推奨）

Python 3.11以上がインストールされていれば、同梱の起動スクリプトだけで動きます:

- **Windows**: `start.bat` をダブルクリック
- **Mac / Linux**: `./start.sh`

初回は依存ライブラリのインストールに数分かかります。
起動後、ブラウザで http://localhost:8000 を開いてください。
管理者トークンは起動時のコンソールに表示されます。

### 手動セットアップ

```bash
pip install -r requirements.txt

# AIコーチングを有効にする場合（任意）
export ANTHROPIC_API_KEY=sk-ant-...

# 管理者トークンを固定する場合（未設定なら起動時に自動生成して表示）
export VALO_COACH_ADMIN_TOKEN=your-secret-token

uvicorn app.main:app --host 0.0.0.0 --port 8000
```

ブラウザで http://localhost:8000 を開きます。

## 使い方

### 1. 学習動画を登録する（サイト運営者専用）

「管理者（学習データ）」タブは**管理者トークンによるログインが必要**です。
トークンは環境変数 `VALO_COACH_ADMIN_TOKEN`、未設定の場合はサーバー起動時に
コンソールへ表示される自動生成トークンを使います。

ログイン後、プロやランク上位（ダイヤ帯以上）の試合動画を2つの方法で登録できます:

- **ファイルアップロード**: 手元の動画ファイルをランクラベル付きで登録
- **YouTubeのURL指定**: URLを入力するとサーバーが動画を取得（yt-dlp）して解析し、
  指定ランク帯の学習データに追加します（2時間以内の公開動画）

登録時に**許諾状態**を記録できます:

- 「権利者の許諾を得ています」にチェック → **許諾済み**として登録
- 未チェック → **開発用（未許諾）**として登録

「学習データ一覧」で全データの出典（アップロード / YouTube / プレイヤー提供）と
許諾状態を確認でき、個別削除・許諾済みへの切り替え・
**開発用データの一括削除**（許諾済みは残る）ができます。
開発中は他人の動画で検出精度をチューニングし、公開前に開発用データだけを
一括削除して許諾済みデータに入れ替える、という運用を想定しています。

- **ダイヤモンド帯の動画を多めに**登録してください。利用者はゴールド→プラチナ帯が
  中心のため、比較対象となるプラチナ・ダイヤモンド帯の精度が最も重要です
- 各ランク帯に数本ずつ登録すると、初期値ではなく実測ベンチマークが使われます
- 学習状況（本数・ベンチマーク値）は同タブの表で確認できます

学習動画が1本もなくても、初期値ベンチマークでコーチング自体は動作します。

### 2. コーチングを受ける（プレイヤー向け）

「コーチングを受ける」タブで:

1. 自分でプレーした1試合分の動画（mp4等）を選択
2. 現在のランクを選択
3. 「解析してコーチングを受ける」を押す

解析後、以下が表示されます:

- **動画プレイヤー**: アップロードした動画を再生しながら解説を確認できます
  （画面上部に固定表示。ラウンド別分析のボタンから該当シーンへジャンプ）
- **総合評価**: 次のランク帯の基準との比較サマリー
- **良かった点 / 改善点**: 指標ベースの診断
- **重点ポイント**: 現在のランク帯から上がるために意識すべきこと
- **ラウンド別分析**: 動画内の時刻付きで各ラウンドの所見を表示
  （問題のあるラウンドは黄色でハイライト。「▶ この場面を見る」で動画がジャンプ）
- **AI詳細レポート**: Claude によるプロコーチ風の詳細指導（APIキー設定時）

### 3. プレイヤー提供動画を学習に活かす（サイト運営者専用）

プレイヤーがコーチング依頼でアップロードした動画の解析結果は、申告ランク付きで
**学習候補**として自動保存されます。管理者タブの「プレイヤー提供動画のレビュー」で:

- 解析サマリーと動画本体を確認し、申告ランクが妥当なら**承認** →
  そのランク帯の学習データ（ベンチマーク）に反映されます
- 妥当でなければ**却下** → 学習には使われません

これにより、利用者が増えるほど各ランク帯のベンチマーク精度が向上していきます。
（プレイヤーの動画を学習に使用する旨は、アップロード欄に明記しています）

### 4. プレイヤーのコメントでサイトを改善する

コーチングタブの下部に「ご意見・ご要望」フォームがあり、プレイヤーは誰でも
コメントを送信できます。送信されたコメントは管理者タブの
「プレイヤーからのコメント」に一覧表示され、対応が済んだものは
「対応済み」にして消し込めます。いただいたコメントをサイト改善に活かしてください。

## API

管理者専用エンドポイントは `X-Admin-Token` ヘッダーが必要です。

| メソッド | パス | 認証 | 説明 |
|---|---|---|---|
| POST | `/api/analyze` | - | `file`（動画）+ `rank` を送信 → `job_id` |
| GET | `/api/jobs/{job_id}` | - | ジョブの進捗・結果取得 |
| GET | `/videos/{video_name}` | - | アップロード動画の再生 |
| GET | `/api/benchmarks` | - | 全ランク帯のベンチマークと学習本数 |
| POST | `/api/feedback` | - | ご意見・ご要望の投稿（`message` + 任意で `rank`） |
| POST | `/api/reference/upload` | 管理者 | 学習動画の登録（`file` + `rank` + `label`） |
| POST | `/api/reference/youtube` | 管理者 | YouTube URLから学習（`url` + `rank` + `label`） |
| GET | `/api/admin/check` | 管理者 | トークン確認 |
| GET | `/api/admin/contributions` | 管理者 | プレイヤー提供動画（学習候補）の一覧 |
| POST | `/api/admin/contributions/{id}/approve` | 管理者 | 候補を学習に反映 |
| POST | `/api/admin/contributions/{id}/reject` | 管理者 | 候補を却下 |
| GET | `/api/admin/feedback` | 管理者 | コメント一覧（`status=new/done/all`） |
| POST | `/api/admin/feedback/{id}/done` | 管理者 | コメントを対応済みにする |
| GET | `/api/admin/references` | 管理者 | 学習データ一覧（出典・許諾状態付き） |
| DELETE | `/api/admin/references/{id}` | 管理者 | 学習データを1件削除 |
| POST | `/api/admin/references/{id}/licensed` | 管理者 | 許諾状態の変更（`{"licensed": true}`） |
| POST | `/api/admin/references/purge-unlicensed` | 管理者 | 未許諾（開発用）データの一括削除 |

## 制限事項・今後の改善

- ラウンド検出はシーンチェンジベースのヒューリスティックのため、実際のラウンドと
  ずれることがあります（HUDタイマーのOCR化で精度向上の余地あり）
- キル/デス数の個人成績はまだ取得していません（キルフィードのOCR化が必要）
- ジョブ管理はプロセス内メモリのため、サーバー再起動で進行中ジョブは消えます
- プレイヤーの動画は結果画面での再生・管理者レビューのためサーバーに保存されます
  （管理者用の学習動画は統計抽出後に削除）。ディスク容量に応じた定期削除は今後の課題です
